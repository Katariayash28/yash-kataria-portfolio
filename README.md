# Yash Kataria — 3D Data Analyst Portfolio

A premium dark 3D portfolio built with React, Vite, Three.js / React Three Fiber and Framer Motion.

## Run locally

1. Install Node.js 20+.
2. Open this folder in VS Code.
3. In the terminal:

```bash
npm install
npm run dev
```

4. Open the local URL printed by Vite.

## Edit

Most content is in `src/main.jsx`.
Visual styling is in `src/styles.css`.

Update:
- name / bio
- metrics
- project descriptions
- GitHub and LinkedIn URLs
- experience timeline
- contact email

## Deploy to Vercel

Push this folder to GitHub, then import the repository in Vercel.

Vercel settings:
- Framework preset: Vite
- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

No environment variables are required for this portfolio.
